# Ageitos Advertising

Marketing website for **Ageitos Advertising** — a personal injury / MVA lead generation company (placeholder brand name).

Inspired by the structure and visual language of Walker Advertising: dark navy + seafoam palette, Lexend Deca headlines, Source Sans 3 body, full-bleed hero, partner-focused sections, and multi-page legal lead funnel.

## Pages

- `/` — Homepage
- `/legal-leads` — MVA & personal injury lead offerings
- `/how-it-works` — Advertise → Connect → Qualify → Optimize
- `/about` — Mission & distinction
- `/contact` — Partnership form

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Phone, email, and testimonials are placeholders — replace before launch.
- Contact form currently confirms client-side only (no CRM/email backend yet).
- Privacy and Terms are stubs for counsel review.
